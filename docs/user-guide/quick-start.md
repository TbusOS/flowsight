# FlowSight 快速开始指南

本指南帮助您在 5 分钟内开始使用 FlowSight 分析 Linux 内核代码。

## 系统要求

| 组件 | 最低要求 | 推荐 |
|------|----------|------|
| 操作系统 | Windows 10 / macOS 12 / Ubuntu 20.04 | Windows 11 / macOS 14 / Ubuntu 22.04 |
| 内存 | 4GB | 8GB+ |
| 磁盘空间 | 500MB | 2GB (含内核源码) |
| Rust | 1.75+ | 最新稳定版 |
| Node.js | 20+ | 最新 LTS |

## 安装

### 方式一：下载预构建版本（推荐）

访问 [GitHub Releases](https://github.com/TbusOS/flowsight/releases) 下载：

| 平台 | 文件 |
|------|------|
| Windows | `flowsight-x.x.x-windows.msi` |
| Linux | `flowsight-x.x.x-linux.AppImage` 或 `.deb` |
| macOS | `flowsight-x.x.x-macos.dmg` |

### 方式二：从源码构建

```bash
# 1. 克隆仓库
git clone https://github.com/TbusOS/flowsight.git
cd flowsight

# 2. 安装依赖
cd app && pnpm install

# 3. 构建并运行
pnpm tauri dev
```

**详细安装说明**：参见 [安装指南](./installation.md)

## 首次使用

### 步骤 1：打开 Linux 内核项目

1. 启动 FlowSight
2. 按 `Cmd+K` (macOS) 或 `Ctrl+K` (Windows/Linux) 打开命令面板
3. 选择 **"打开项目"**
4. 选择 Linux 内核源码目录（如 `/path/to/linux`）

```
推荐测试目录：
├── arch/arm/mach-imx/    # ARM32 平台代码（142 个文件）
├── drivers/usb/          # USB 驱动
└── drivers/net/          # 网络驱动
```

### 步骤 2：等待索引完成

FlowSight 会自动扫描并索引项目：

```
状态栏显示：
🔄 索引中: 15,234 符号...
✅ 索引完成: 15,234 符号
```

> 💡 **提示**：首次索引可能需要 10-30 秒，取决于项目大小。

### 步骤 3：打开源文件

1. 使用文件浏览器（左侧面板）导航
2. 或按 `Cmd+P` 搜索文件名
3. 点击打开 `.c` 或 `.h` 文件

**推荐测试文件**：
- `arch/arm/mach-imx/clk-imx6q.c` - 时钟驱动
- `drivers/usb/core/driver.c` - USB 核心
- `drivers/net/ethernet/intel/e1000/e1000_main.c` - 网卡驱动

### 步骤 4：查看执行流

1. 在代码编辑器中，点击一个函数名
2. 右侧面板自动显示该函数的执行流图
3. 点击流程图中的节点可以跳转到对应代码

## 执行流颜色含义

FlowSight 使用颜色标识不同的执行上下文：

| 颜色 | 上下文 | 可睡眠 | 说明 |
|------|--------|--------|------|
| 🟢 绿色 | 进程上下文 | ✅ 是 | 普通函数调用 |
| 🟠 橙色 | 软中断 | ❌ 否 | SoftIRQ/Tasklet |
| 🔴 红色 | 硬中断 | ❌ 否 | 中断处理程序 |
| 🔵 蓝色 | 工作队列 | ✅ 是 | WorkQueue handler |
| 🟣 紫色 | 定时器 | ❌ 否 | Timer callback |

## 常见问题

### Q: 为什么执行流图是空的？

A: 可能的原因：
1. 文件还在索引中，请等待索引完成
2. 选中的函数没有被其他函数调用
3. 文件不是 C/C++ 源文件

### Q: 如何分析特定函数？

A: 在代码中点击函数名，或在命令面板搜索函数名后选择 "分析执行流"。

### Q: 支持哪些内核版本？

A: FlowSight 支持 Linux 4.0+ 内核，知识库针对 5.x/6.x 内核优化。
