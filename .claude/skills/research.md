# /sc:research - 网络研究

> FlowSight 网络研究技能

## 自动触发条件

当任务描述包含以下关键词时，自动激活此技能：

| 触发关键词 | 说明 |
|-----------|------|
| "研究", "research" | 网络研究 |
| "查找", "search" | 信息查找 |
| "了解", "learn" | 技术学习 |

## 使用方式

```
/sc:research "LLVM IR 规范"
/sc:research "KLEE 符号执行"
/sc:research "最新 Rust 异步编程"
```

## 研究内容

### 技术研究

- LLVM IR 指令集
- 符号执行技术
- Rust 异步编程
- 前端框架最佳实践

### 规范查阅

- 语言规范
- API 文档
- 设计模式
- 最佳实践

### 工具调研

- 开发工具评估
- 库/crate 对比
- 性能工具选择

## 研究方法

1. **明确问题** - 确定研究目标
2. **搜索信息** - 查找相关资料
3. **分析整理** - 提取关键信息
4. **应用建议** - 提出实施方案

## 研究工具

### 网络搜索

- 使用 Tavily 搜索
- 查阅官方文档
- 参考开源项目

### 本地资源

- 查看知识库
- 搜索代码注释
- 阅读现有文档

## 输出格式

### 研究报告

```markdown
## 主题: [研究主题]

### 概述
```
