# /sc:collaborative-dev - 三智能体协作开发

> **FlowSight 专用多智能体协作技能**
>
> 根据任务自动分析并分配智能体，无需手动选择

## 自动触发条件

当任务描述包含以下关键词时，自动激活此技能：

| 触发关键词 | 说明 |
|-----------|------|
| "协作", "一起", "多个" | 多人协作开发任务 |
| "并行", "同时" | 并行开发任务 |
| "三智能体" | 明确要求三智能体协作 |
| "完整功能" | 需要前后端完整实现 |

## 任务自动分析

### 分析维度

当技能激活后，自动分析任务描述：

| 分析维度 | 检测内容 | 影响 |
|----------|----------|------|
| **技术栈** | Rust (.rs), React (.tsx) | 决定激活哪些 Agent |
| **功能类型** | API, UI 组件, 解析器 | 决定任务分配 |
| **复杂度** | 简单/中等/复杂 | 决定并行度 |
| **依赖关系** | 前后端依赖 | 决定执行顺序 |

### 智能体分配规则

```
任务描述 → 自动分析 → 智能分配

┌─────────────────────────────────────────────────────────────┐
│                    任务分析引擎                              │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  关键词检测 → 激活对应 Agent                                 │
│                                                              │
│  ┌─────────────────┬────────────────────────────────────┐  │
│  │ 检测到          │ 激活的 Agent                       │  │
│  ├─────────────────┼────────────────────────────────────┤  │
│  │ Rust/API/解析器 │ Core-Agent                        │  │
│  │ React/UI/界面   │ UI-Agent                          │  │
│  │ 测试/验证       │ Test-Agent                        │  │
│  │ 完整功能        │ Core + UI + Test (全部)           │  │
│  └─────────────────┴────────────────────────────────────┘  │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 任务类型识别示例

| 任务示例 | 识别类型 | 自动分配 |
|---------|---------|---------|
| "实现 API" | 后端开发 | Core + Test |
| "美化 UI" | 前端开发 | UI + Test |
| "实现完整功能" | 全栈开发 | Core + UI + Test |
| "优化性能" | 性能优化 | 根据影响范围分配 |

## 智能体角色

| 智能体 | 角色 | 专长领域 |
|--------|------|----------|
| 🤖 **Core-Agent** | 核心开发 | Rust 后端、API、数据结构 |
| 🎨 **UI-Agent** | 前端开发 | React 组件、交互设计、样式 |
| 🧪 **Test-Agent** | 测试保障 | 单元测试、集成测试、验证 |

## 使用方式

只需描述任务，技能自动分析并分配：

```
/sc:collaborative-dev "实现节点详情面板"
```

**自动执行流程**:
1. 分析任务关键词
2. 分配合适的智能体
3. 并行执行开发
4. 自动测试验证
5. 合并结果
