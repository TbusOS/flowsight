# /sc:load-core - 加载完整框架

> SuperClaude Framework 核心加载技能

## 使用方式

```
/sc:load-core    # 加载完整框架
```

## 功能说明

此命令用于在 Claude Code 启动时加载完整的 SuperClaude Framework。

### 自动加载

FlowSight 项目配置了自动加载，CLAUDE.md 会自动加载框架，无需手动执行。

### 手动加载

如果自动加载失败，可手动执行：

```
/sc:load-core
```

## 加载内容

- 所有配置的 Skills
- 任务感知规则
- 开发规范
- 工具集成

## 与其他 Skills 配合

```
/sc:load-core    # 加载框架
/sc:help         # 验证加载
```
