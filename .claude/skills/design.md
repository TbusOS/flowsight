# /sc:design - 系统架构设计

> FlowSight 系统架构设计技能

## 自动触发条件

当任务描述包含以下关键词时，自动激活此技能：

| 触发关键词 | 说明 |
|-----------|------|
| "设计", "architecture" | 架构设计任务 |
| "架构", "structure" | 系统结构设计 |
| "模式", "pattern" | 设计模式应用 |

## 使用方式

```
/sc:design "设计 LLVM 模块架构"
/sc:design "设计符号执行引擎"
/sc:design "设计前端组件通信模式"
```

## 设计原则

### Rust 后端设计

- 遵循 Rust 所有权系统最佳实践
- 使用 trait 定义抽象接口
- 保持模块间低耦合、高内聚
- 异步代码使用 Tokio runtime

### React 前端设计

- 组件职责单一
- 状态管理使用 Zustand
- UI 组件与业务逻辑分离
- 遵循响应式设计原则

## 输出内容

- 模块依赖关系图
- 数据结构定义
- API 接口设计
- 错误处理策略

## 与其他 Skills 配合

```
1. /sc:design "设计架构"
2. /sc:implement "实现功能"
3. /sc:test "运行测试"
4. /sc:build "构建验证"
```
