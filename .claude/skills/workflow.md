# /sc:workflow - 工作流生成

> FlowSight 工作流生成技能

## 自动触发条件

当任务描述包含以下关键词时，自动激活此技能：

| 触发关键词 | 说明 |
|-----------|------|
| "工作流", "workflow" | 工作流生成 |
| "流程", "process" | 开发流程 |
| "步骤", "steps" | 任务步骤 |

## 使用方式

```
/sc:workflow "从计划生成工作流"
/sc:workflow "分解实现任务"
/sc:workflow "创建开发计划"
```

## 工作流类型

### 功能开发工作流

```
1. 需求分析
   - 理解功能需求
   - 确定输入输出

2. 架构设计
   - 设计数据结构
   - 定义接口

3. 代码实现
   - 实现核心逻辑
   - 添加错误处理

4. 测试验证
   - 编写单元测试
   - 集成测试

5. 代码审查
   - 自查代码
   - 运行 clippy
```

### 调试工作流

```
1. 问题收集
   - 收集错误信息
   - 记录复现步骤

2. 原因分析
   - 分析错误堆栈
   - 检查相关代码

3. 解决方案
   - 制定修复计划
   - 实施修复

4. 验证测试
   - 运行测试
   - 确认修复
```

### 性能优化工作流

```
1. 性能测量
   - 基准测试
   - 性能分析

2. 瓶颈识别
   - 分析热点
   - 确定优化点

3. 实施优化
   - 代码优化
   - 算法改进

4. 效果验证
   - 重新测量
   - 对比改进
```

## 工作流模板

### 完整功能开发

```yaml
name: 完整功能开发
stages:
  - name: 需求分析
    tasks:
      - 理解需求
      - 确定范围

  - name: 架构设计
    tasks:
      - 设计接口
      - 定义结构

  - name: 代码实现
    tasks:
      - 核心逻辑
      - 错误处理

  - name: 测试验证
    tasks:
      - 单元测试
      - 集成测试

  - name: 代码清理
    tasks:
      - clippy 检查
      - fmt 格式化
```

```

2. /sc:implement "执行实现"
3. /sc:test "运行测试"
4. /sc:build "构建验证"
```
