# /sc:help - 查看所有 Skills

> SuperClaude Framework 帮助技能

## 使用方式

```
/sc:help    # 查看所有可用 skills
/sc:help /sc:design    # 查看特定 skill 详情
```

## 功能说明

此命令用于查看和了解所有可用的 SuperClaude Framework skills。

## 可用 Skills

### 核心开发 Skills

| Skill | 用途 | 示例 |
|-------|------|------|
| `/sc:design` | 系统架构设计 | `/sc:design "设计 LLVM 模块"` |
| `/sc:implement` | 功能代码实现 | `/sc:implement "实现 memory.yaml"` |
| `/sc:build` | 项目构建 | `/sc:build --release` |
| `/sc:test` | 测试执行 | `/sc:test -p flowsight-analysis` |
| `/sc:analyze` | 代码分析 | `/sc:analyze --security` |

### 诊断与调试 Skills

| Skill | 用途 | 示例 |
|-------|------|------|
| `/sc:troubleshoot` | 问题诊断 | `/sc:troubleshoot "编译错误"` |
| `/sc:cleanup` | 代码清理 | `/sc:cleanup "移除死代码"` |
| `/sc:improve` | 代码改进 | `/sc:improve "性能优化"` |

### 文档与研究 Skills

| Skill | 用途 | 示例 |
|-------|------|------|
| `/sc:document` | 文档生成 | `/sc:document "API 文档"` |

| `/sc:explain` | 代码解释 | `/sc:explain "解释这个函数"` |

### 项目管理 Skills

| Skill | 用途 | 示例 |

| `/sc:workflow` | 工作流生成 | `/sc:workflow "从计划生成"` |

### 版本控制 Skills

| `/sc:load-flags` | 加载配置模式 |

## 查看 Skill 详情

```
/sc:help /sc:design     # 查看 design skill
/sc:help /sc:implement  # 查看 implement skill
/sc:help /sc:build      # 查看 build skill
```

---

**快捷命令**:

```
/sc:help          # 查看所有 skills
/sc:help <skill>  # 查看特定 skill 详情
```
