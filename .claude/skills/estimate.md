# /sc:estimate - 任务估算

> FlowSight 任务估算技能

## 自动触发条件

当任务描述包含以下关键词时，自动激活此技能：

| 触发关键词 | 说明 |
|-----------|------|
| "估算", "estimate" | 任务估算 |
| "估计", "estimate" | 时间估算 |
| "工时", "effort" | 工作量估算 |

## 使用方式

```
/sc:estimate "Phase 1 估算"
/sc:estimate "实现功能工作量"
/sc:estimate "重构模块时间"
```

## 估算维度

### 代码量估算

- 根据功能复杂度估算代码行数
- 考虑测试代码量
- 预留文档编写时间

### 复杂度评估

| 复杂度 | 说明 | 系数 |
|--------|------|------|
| 简单 | 独立函数/组件 | 1x |
| 中等 | 需要设计的小模块 | 2x |
| 复杂 | 多模块交互 | 3x |
| 非常高 | 核心系统改动 | 5x |

### 风险评估

- 技术风险
- 依赖风险
- 集成风险

## 估算方法

### 三点估算法

```
乐观时间 (O) + 4 * 最可能时间 (M) + 悲观时间 (P)
----------------------------------------------------
                          6
```

### 类比估算法

- 参考类似任务历史
- 根据经验调整

## 估算输出

### 估算报告

```markdown
## 任务: [任务名称]

### 估算结果
- 乐观时间: X 天
- 最可能时间: Y 天
- 悲观时间: Z 天
- 期望时间: W 天

### 详细分析
- 代码量: LOC
- 复杂度: 中等
- 风险: 低/中/高

### 假设条件
1. 假设1
2. 假设2

### 风险因素
- 风险1 (影响: 低)
- 风险2 (影响: 中)
```
