# /sc:load-flags - 加载配置模式

> SuperClaude Framework 配置模式加载技能

## 使用方式

```
/sc:load-flags    # 加载配置模式
```

## 功能说明

此命令用于加载 SuperClaude Framework 的配置模式和运行参数。

### 加载内容

- 行为标志配置
- 执行模式设置
- 工具权限配置
- 任务感知规则

## 配置模式

### development 模式

FlowSight 使用 development 模式：
- 详细日志输出
- 完整的错误信息
- 调试工具集成

### production 模式

- 最小日志输出
- 优化性能
- 安静执行

## 与其他 Skills 配合

```
/sc:load-core     # 加载核心框架
/sc:load-flags    # 加载配置模式
/sc:load-rules    # 加载开发规则
```
